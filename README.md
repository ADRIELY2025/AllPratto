 #  ALL PRATTO

Sistema web de cardápio digital desenvolvido como Projeto Integrador do Curso Técnico em Informática do Serviço Nacional de Aprendizagem Comercial – SENAC.

O projeto tem como objetivo modernizar o atendimento de restaurantes de pequeno porte através de uma plataforma digital capaz de realizar pedidos em tempo real, integrando clientes, administração e cozinha em um único sistema.

---

##  Objetivo

Desenvolver uma solução web acessível para otimizar o processo de pedidos em restaurantes, reduzindo falhas de comunicação, melhorando o atendimento e automatizando o gerenciamento operacional.

---

##  Funcionalidades

-  Cardápio digital via QR Code
-  Realização de pedidos online
-  Painel administrativo com autenticação
-  Painel da cozinha com atualização em tempo real
-  Controle de faturamento
-  Gerenciamento de produtos, mesas e pedidos

---

##  Tecnologias Utilizadas

- PHP
- PostgreSQL
- JavaScript
- HTML5
- CSS
- Node.js
